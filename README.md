# Student Performance Prediction using Machine Learning

## 📌 Project Overview

This is a Machine Learning project that predicts student performance based on various factors. The model analyzes different student-related attributes and predicts whether a student is likely to pass or fail.

The main objective of this project is to use machine learning techniques to identify patterns in student data and build a predictive system that can help understand the factors affecting academic performance.

---

## 🎯 Problem Statement

Student performance depends on multiple factors such as study habits, academic background, attendance, and other personal attributes. This project aims to develop a machine learning model that can predict student outcomes based on these factors.

---

## 🚀 Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature selection and transformation
- Machine Learning model training
- Performance evaluation
- Student pass/fail prediction through a Streamlit web application

---

## 🛠️ Technologies Used

## 📂 Dataset

The dataset contains various student-related features that influence academic performance.

The model uses these features to learn patterns and predict the final result:

- Student academic details
- Study-related factors
- Performance indicators
- Other relevant attributes
